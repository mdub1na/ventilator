# Kotlin/JVM read-only bridge

Минимальный Kotlin-прототип читает компактный JSON из `smc-read --status-json` и рассчитывает уровень каждого вентилятора по его фактическим RPM и собственному диапазону. Единый уровень для значка — максимум из двух. Тот же модуль умеет разбирать `--temperatures-json` для исследовательского списка ключей; в [Compose окне](../desktop-app/README.md) этот список не показывается. Никаких операций записи в SMC нет.

`FanSnapshot` и `TemperatureReading` сохраняют исходный SMC-ключ, источник, единицу, момент обработки снимка и уровень уверенности в подписи. `TCMz` помечен как наблюдавшийся на `Mac15,7` максимум кристалла CPU; физическое расположение вентиляторов по `F0Ac`/`F1Ac` не установлено, поэтому их подписи остаются сырыми. `0 RPM` — доступное показание и 0 делений даже при недоступном диапазоне; `null` — недоступное чтение. Для положительных RPM без корректного `Mn`/`Mx` уровень неизвестен. Время не является аппаратной меткой SMC. При ошибке запуска или разбора утилиты чтение завершается ошибкой, а не выдаёт фиктивные нули.

```bash
make -C ../smc-read build
gradle --offline run --args=../smc-read/smc-read
gradle --offline test
```

Это проверка связки Kotlin/JVM → нативное чтение через локальный процесс; этот CLI печатает один снимок в терминал. Compose прототип локально включает reader в `.app`, однако подпись пакета, проверка целостности пути и IPC будущего привилегированного помощника остаются открытыми.
