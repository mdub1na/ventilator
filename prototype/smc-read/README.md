# Read-only SMC probe

Минимальный аппаратный прототип для MacBook Pro M3 Pro (`Mac15,7`). Он использует публичный механизм подключения IOKit и наблюдаемый в открытых реализациях протокол AppleSMC. В исходнике есть только селекторы чтения `5`, `8`, `9`; команды записи нет.

```bash
cd prototype/smc-read
make run
./smc-read --all-temperatures
./smc-read --status-json
```

Запускайте в обычном Terminal от своего пользователя, без `sudo`. В песочнице Codex открытие AppleSMC на этой машине вернуло `kIOReturnNotPermitted`; сама утилита после запуска вне неё прочитала данные.

`FNum` сообщает число вентиляторов, `F{n}Ac` — наблюдаемые обороты, `F{n}Tg` — цель, `F{n}Mn`/`F{n}Mx` — границы, `F{n}Md`/`F{n}md` — режим. Наличие ключа показывает, что его можно прочитать, **но не доказывает доступность записи**. Значение режима не следует интерпретировать как разрешение ручного управления без отдельного опыта.

Температурные ключи выводятся как сырые четырёхсимвольные ID и градусы Цельсия. Фильтр по диапазону отсеивает очевидно неподходящие значения, но сам по себе не устанавливает, какому компоненту принадлежит датчик. Для UI понадобятся проверенные подписи или нейтральные названия.

`--status-json` выдаёт одну строку JSON со схемой 1: количество вентиляторов, для каждого фактические RPM и `Mn`/`Mx`, а также `TCMz` в °C. Недоступное чтение выдаётся как `null`, не как ноль. На других моделях привязку `TCMz` к CPU необходимо проверить отдельно. Этот формат читает [Kotlin/JVM прототип](../kotlin-read/README.md).

## Повторяемая проверка реакции датчиков

```bash
make build
python3 thermal-study.py --output /private/tmp/ventilator-thermal-study.jsonl
```

Скрипт делает 3 снимка в покое, затем запускает 4 вычислительных процесса максимум на 30 секунд и делает 3 снимка после нагрузки. Он вызывает только `smc-read --all-temperatures`, пишет строки JSON с фазой, температурами и RPM и завершает нагрузку даже при ошибке чтения. Никаких команд изменения скорости он не вызывает. Не запускайте его параллельно с другими стресс-тестами, если нужна сопоставимая реакция датчиков. На `Mac15,7` локальный опыт 2026-09-22 описан в [исследовании](../../docs/research/research-architecture.md): для строки меню выбран `TCMz` с рабочей подписью «CPU die max»; переносить эту карту на другие модели нельзя без проверки.

Протокол сверялся с [реализацией macfan](https://github.com/raminsharifi/MacFanControl/blob/main/src/smc.rs) и [документацией Apple для IOServiceOpen](https://developer.apple.com/documentation/iokit/1514515-ioserviceopen). Данные относятся только к запущенной модели и версии macOS.
