# Compose Desktop окно мониторинга

Окно и строка меню для `Mac15,7` на Kotlin/JVM 2.4.20, Compose Multiplatform Desktop 1.12.0, Material 3 `1.12.0-alpha03` с `MaterialExpressiveTheme` и Swift/AppKit. Источник данных — [локальный reader](../smc-read/README.md) на C/IOKit через [модель Kotlin](../kotlin-read/README.md). Запись в SMC отсутствует.

Окно обновляет температуры CPU (`TCMz`), GPU (`Tg0D`) и предполагаемого датчика SSD (`TH0a`) вместе с фактическими RPM двух вентиляторов каждые 2 секунды. Три температурные карточки расположены над карточками вентиляторов с индивидуальными пятисегментными шкалами. `Tg0D` вырос примерно с 45 до 68 °C при 22-секундной нагрузке GPU на `Mac15,7`; привязка `TH0a` к SSD основана на открытых картах SMC и остаётся предварительной. В карточках видны сырые ключи. Разделы других температур и диагностики датчиков убраны из окна; команда reader для полного списка ключей сохранена для исследований.

При ручном запуске окно открыто. Обычный щелчок по значку переключает видимость окна; его закрытие красной кнопкой или пункт «Скрыть окно» в контекстном меню оставляет процесс и опрос работающими. Пункт «Открыть окно» показывает окно снова, «Выход» завершает оба процесса. Контекстное меню открывается нажатием двумя пальцами по значку. Kotlin передаёт снимок в AppKit через локальный stdin/stdout дочернего процесса: Swift не читает SMC и не рассчитывает уровни повторно. Значок объединяет вентилятор, пятиделённую шкалу по максимальному из двух индивидуальных уровней и `TCMz` в °C.

Нужны macOS Apple Silicon, JDK 25, Gradle, Xcode Command Line Tools и доступ к зависимостям Gradle для первого запуска. Из этого каталога:

```bash
gradle :test
gradle :run
gradle createDistributable -Pcompose.desktop.packaging.checkJdkVendor=false
```

`gradle :run` сам собирает `smc-read` и `status-item-bridge` и использует соседние каталоги исходников. `createDistributable` включает оба исполняемых файла в `build/compose/binaries/main/app/Ventilator.app`; флаг проверки vendor нужен для локального Homebrew JDK 25. Для прямого запуска собранного пакета используйте Finder. Reader не требует `sudo` на проверенной модели. Перед повторной упаковкой завершите открытую копию приложения: `jpackage` не может переподписать её работающий Java runtime.

Это локальная неподписанная сборка для проверки, а не готовый дистрибутив. Автозапуск намечен на M1-04, подпись и нотарификация — на M3, управление скоростью — на M2. Исходники [изолированного AppKit прототипа](../menu-bar/README.md) сохранены для проверки рисунка; при обычном запуске `.app` создаётся один статусный элемент.
