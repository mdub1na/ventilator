# Compose Desktop окно мониторинга

Самостоятельное окно для `Mac15,7` на Kotlin/JVM 2.4.20, Compose Multiplatform Desktop 1.12.0 и Material 3 `1.12.0-alpha03` с `MaterialExpressiveTheme`. Источник данных — [локальный reader](../smc-read/README.md) на C/IOKit через [модель Kotlin](../kotlin-read/README.md). Запись в SMC отсутствует.

Окно обновляет `TCMz` и фактические RPM двух вентиляторов каждые 2 секунды, показывает индивидуальные пятисегментные шкалы и выбранные температуры `TAOL`, `TB0T`, `TCMb` только под сырыми ключами. При открытии диагностики один раз считывает полный перечень температурных ключей; поиск фильтрует их по ID, кнопка повторяет чтение. На `Mac15,7` локальный запуск упакованного `.app` отобразил 252 ключа. Значения в диагностике могут быть старее показаний основного экрана.

Нужны macOS Apple Silicon, JDK 25, Gradle, Xcode Command Line Tools и доступ к зависимостям Gradle для первого запуска. Из этого каталога:

```bash
gradle :test
gradle :run
gradle createDistributable -Pcompose.desktop.packaging.checkJdkVendor=false
```

`gradle :run` использует `../smc-read/smc-read`: соберите его заранее командой `make -C ../smc-read build`, если ещё нет файла. `createDistributable` сам собирает C reader и включает его в `build/compose/binaries/main/app/Ventilator.app`; флаг проверки vendor нужен для локального Homebrew JDK 25. Для прямого запуска собранного пакета используйте Finder. Reader уже включён в пакет и не требует `sudo` на проверенной модели.

Это локальная неподписанная сборка для проверки, а не готовый дистрибутив. Она открывает отдельное окно, которое при закрытии завершает мониторинг. Нативный прототип значка строки меню существует [отдельно](../menu-bar/README.md); объединение процессов и сохранение опроса при скрытом окне намечены на M1-03, автозапуск на M1-04. Подпись и нотарификация — M3, управление скоростью — M2.
