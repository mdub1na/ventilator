# Составной значок в строке меню macOS

Изолированная проверка AppKit `NSStatusItem`: один элемент показывает цветную пятисегментную шкалу и температуру `TCMz`. Нажатие открывает системное меню с RPM обоих вентиляторов и выходом. Процесс читает `smc-read --status-json` каждые две секунды, ничего не записывает в SMC и не требует `sudo` в обычном пользовательском окружении.

```bash
make -C ../smc-read build
make build
make run
```

Это нативный технический прототип значка, пока без основного окна Compose. Он нужен для проверки цвета, размера и поведения меню на реальном Mac; способ связи с будущим Kotlin/JVM окном и упаковка в `.app` ещё открыты.

Температура в значке — `TCMz`, рабочая подпись «CPU die max» для `Mac15,7`; это максимум температуры внутри кристалла, а не температура корпуса. В меню подпись раскрыта. Слева от шкалы нарисован вентилятор с направленным вправо потоком воздуха. Все пять делений, включая цветные, имеют тонкие белые контуры. Пользователь подтвердил читаемость белой шкалы на тёмной строке меню до последнего изменения толщины и добавления вентилятора; эту версию и светлую тему ещё нужно проверить визуально.
