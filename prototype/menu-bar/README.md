# Составной значок в строке меню macOS

AppKit `NSStatusItem`: один элемент показывает цветную пятисегментную шкалу и температуру `TCMz`. Обычный щелчок переключает видимость Compose окна; контекстный щелчок двумя пальцами по тачпаду открывает меню с RPM обоих вентиляторов, открытием/скрытием окна и выходом. Оба жеста проверены пользователем на `Mac15,7` 2026-09-22. В составе [настольного приложения](../desktop-app/README.md) запускается `status-item-bridge`: он получает готовые показания и рассчитанный уровень от Kotlin по stdin, а команды меню отправляет по stdout. Он не читает AppleSMC сам.

```bash
make -C ../smc-read build
make build
make run
```

Команда `make run` запускает сохранённый изолированный прототип `status-item`, который по-прежнему сам опрашивает `smc-read` и не связан с окном. В обычном `.app` он не запускается. Общий рисунок находится в `StatusArtwork.swift`; `StatusItemBridge.swift` обрабатывает локальный протокол `snapshot\tlevel\tTCMz\tF0Ac\tF1Ac\twindowVisible` и команды `show`, `hide`, `toggle`, `quit`.

Температура в значке — `TCMz`, рабочая подпись «CPU die max» для `Mac15,7`; это максимум температуры внутри кристалла, а не температура корпуса. В меню подпись раскрыта. Слева от шкалы нарисован вентилятор с направленным вправо потоком воздуха. Все пять делений, включая цветные, имеют тонкий контур: белый на тёмной теме, чёрный на светлой. Пользователь подтвердил читаемость в обеих темах на локальном `.app` 2026-09-22.

После сообщения о длительном `0 RPM` обнаружено, что прежний `Timer.scheduledTimer` работал только в обычном режиме цикла AppKit: при открытом меню показания могли оставаться старыми. В изолированном прототипе таймер переведён в common modes. В интегрированном приложении Swift не опрашивает SMC; Kotlin продолжает опрос независимо от открытого меню и скрытого окна. Прямое чтение `smc-read` в момент первоначального исправления показывало ≈1350 и ≈1458 RPM; ранее эта же утилита фиксировала `0 RPM`, поэтому по одному старому снимку нельзя установить, были ли вентиляторы тогда остановлены.
