# Составной значок в строке меню macOS

Изолированная проверка AppKit `NSStatusItem`: один элемент показывает цветную пятисегментную шкалу и температуру `TCMz`. Нажатие открывает системное меню с RPM обоих вентиляторов и выходом. Процесс читает `smc-read --status-json` каждые две секунды, ничего не записывает в SMC и не требует `sudo` в обычном пользовательском окружении.

```bash
make -C ../smc-read build
make build
make run
```

Это нативный технический прототип значка, пока без основного окна Compose. Он нужен для проверки цвета, размера и поведения меню на реальном Mac; способ связи с будущим Kotlin/JVM окном и упаковка в `.app` ещё открыты.

Температура в значке — `TCMz`, рабочая подпись «CPU die max» для `Mac15,7`; это максимум температуры внутри кристалла, а не температура корпуса. В меню подпись раскрыта. Слева от шкалы нарисован вентилятор с направленным вправо потоком воздуха. Все пять делений, включая цветные, имеют тонкие белые контуры. Пользователь подтвердил внешний вид этой версии на тёмной строке меню снимком экрана 2026-09-22. Светлую тему ещё нужно проверить визуально.

После сообщения о длительном `0 RPM` обнаружено, что прежний `Timer.scheduledTimer` работал только в обычном режиме цикла AppKit: при открытом меню показания могли оставаться старыми. Теперь опрос добавлен в common modes и запускается также при открытии меню. Сборка и запуск исправленного процесса прошли; обновление **во время открытого меню** ещё требует пользовательской проверки. Прямое чтение `smc-read` в момент исправления показывало ≈1350 и ≈1458 RPM; ранее эта же утилита фиксировала `0 RPM`, поэтому по одному старому снимку нельзя установить, были ли вентиляторы тогда остановлены.
