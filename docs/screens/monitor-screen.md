## 0. Вход и видимость

- **Вход:** Compose Desktop окно `Ventilator · Мониторинг` при ручном запуске локального `.app` или `gradle :run`; далее обычный щелчок по единому значку либо пункт «Открыть окно» в его контекстном меню. При запуске как объект входа окно должно оставаться скрытым; повторный вход ещё не проверен.
- **Видимость:** при ручном запуске окно открывается сразу. Обычный щелчок по значку переключает видимость окна. Красная кнопка закрытия или пункт «Скрыть окно» скрывают окно; опрос и значок продолжают работать. Нажатие двумя пальцами по значку открывает контекстное меню. Полный выход — отдельный пункт меню.
- **Стиль:** тёмная цветовая схема, `MaterialExpressiveTheme`, карточки Material 3. Пользовательского дизайн-артборда и эталонного сравнения пока нет.

## 1. Состояния экрана

- [x] **Loading (`LOADING`):** до первого снимка три температуры показывают «—», вентиляторы ожидают показаний; кнопка обновления занята.
- [x] **Running (`RUNNING`):** фактические RPM хотя бы одного вентилятора положительны; температуры CPU, GPU и предполагаемого датчика SSD доступны по мере чтения своих ключей.
- [x] **Stopped (`STOPPED`):** каждый обнаруженный вентилятор сообщает 0 RPM, шкалы имеют 0 заполненных делений; это не диагностика поломки.
- [x] **Unavailable (`UNAVAILABLE`):** неизвестно число вентиляторов, не хватает строк или хотя бы один RPM недоступен. Каждая температура независимо показывает «—» при отсутствии своего ключа или значения.
- [x] **No fans (`NO_FANS`):** `FNum = 0`; вместо карточек пояснение об отсутствии вентиляторов.
- [x] **Error (`ERROR`):** ошибка первого запуска или разбора reader; сообщение и ручное обновление. После ошибки последующего опроса последние данные остаются видимыми вместе с сообщением об ошибке, а значок показывает неизвестные показания.
- [x] **Login item disabled / enabled:** переключатель показывает статус `SMAppService`, а не сохранённую локально настройку; включение и выключение проверены в упакованном `.app`.
- [x] **Login item requires approval:** после отзыва разрешения переключатель выключен, есть действие «Открыть настройки входа»; восстановление разрешения возвращает включённое состояние.
- [x] **Login item unavailable / error:** при `gradle run` нативный мост отсутствует, действие выключено; ошибка регистрации не превращается в включённое состояние.

## 2. Интеграция

HTTP API нет. `SmcMonitorRepository` вызывает локальный `smc-read --status-json` через Kotlin/JVM `readSnapshot`. Контракт и таймаут находятся в [документе сервиса](../services/smc-reader-prototype.md). `MonitorViewModel` объединяет снимок и UI-флаги через `combine` и `stateIn` и опрашивает reader каждые 2 секунды независимо от видимости окна.

`TrayReading` формируется из того же `StatusSnapshot` и передаётся дочернему AppKit-процессу через stdin; команды значка возвращаются по stdout. AppKit не делает собственного опроса SMC. Команда reader `--temperatures-json` остаётся для исследований, но в окне нет разделов «Другие температуры» и «Диагностика датчиков».

Настройка автозапуска использует [локальный JNI мост](../services/login-item-bridge.md) в основном JVM-процессе. `LoginItemViewModel` опрашивает реальный статус регистрации каждые 2 секунды, поэтому изменение разрешения в macOS отражается в открытом окне.

## 3. Инициализация

**Входные параметры:** явный путь к `smc-read` первым аргументом, иначе ресурс `.app`, иначе `../smc-read/smc-read` из Gradle проекта. Карту датчиков предполагаем проверенной только на `Mac15,7`.

При инициализации запускается один `status-item-bridge`; упакованный путь берётся из ресурсов `.app`, при `gradle :run` — из `../menu-bar/status-item-bridge`. Если процесс значка завершится, окно показывается с сообщением об ошибке, чтобы приложение оставалось доступным. В упакованном `.app` загрузка `liblogin-item.dylib` и установка наблюдателя Apple Event происходят до Compose/AppKit; обычный запуск открывает окно, признак объекта входа оставляет его скрытым. Если начальное событие не получено за 3 секунды, окно открывается, чтобы ручной запуск не застрял скрытым.

| Вызов | Условие | Результат |
|---|---|---|
| `refreshStatus` | сразу при создании view model и затем каждые 2 секунды | `TCMz`, `Tg0D`, `TH0a`, RPM и диапазоны вентиляторов |

| Результат | Обработка | Состояние |
|---|---|---|
| Валидный снимок | заменить `status`, очистить ошибку | **Running**, **Stopped**, **Unavailable** или **No fans** |
| Недоступный ключ | отдельное значение «—», без ложного нуля | **Unavailable** для RPM; каждая температура независимо |
| Ошибка процесса или JSON | показать текст ошибки и оставить последний успешный снимок в окне | **Error** без снимка; сообщение над прежним состоянием при наличии снимка |

## 4. Элементы сверху вниз

### 4.1. Заголовок и обновление

- **Поле:** `MonitorUiState.refreshing`, `error`.
- **Вид:** название, пометка «только чтение», кнопка «Обновить»/«Обновляем…», текст ошибки при наличии.
- **Действие:** `MonitorUiAction.Refresh` повторно читает короткий снимок; параллельные чтения сериализуются.

### 4.2. Температуры CPU, GPU и SSD

- **Поле:** `temperatures` в фиксированном порядке CPU → GPU → SSD.
- **Вид:** три равные карточки над вентиляторами, каждая показывает °C или «—» и сырой ключ. CPU: `TCMz`, максимум кристалла, рабочая подпись на этой модели. GPU: `Tg0D`, реакция 44,5 → 67,6 °C при 22-секундной нагрузке Metal на этой машине. SSD: `TH0a`, предварительная привязка по открытым картам SMC, так и подписана в карточке.
- **Действие:** нет. Отсутствие ключа не подменяется значением другого датчика.

### 4.3. Две карточки вентиляторов

- **Поле:** `fans`: сырой `F0Ac`/`F1Ac`, `rpm`, `level`, `state`, `range`.
- **Вид:** RPM, индивидуальная пятисегментная зелёно-красная шкала по собственным `Mn`/`Mx`, состояние и диапазон. При 0 RPM шкала пуста, при неизвестном диапазоне «—/5».
- **Действие:** нет; запись и регуляторы не реализованы.

### 4.4. Подпись режима

Текст поясняет, что macOS управляет скоростью вентиляторов и нулевые обороты сами по себе не означают поломку.

### 4.5. Запуск при входе

- **Поле:** `LoginItemUiState.enabled`, `toggleAvailable`, `requiresApproval`, `message`, `error`.
- **Вид:** карточка под вентиляторами с переключателем и фактическим статусом. Пока служба не зарегистрирована, состояние выключено; `notFound` до первой регистрации также допускает включение. При запросе разрешения появляется кнопка перехода к системным объектам входа. При недоступном мосте переключатель недоступен.
- **Действие:** `LoginItemUiAction.SetEnabled` вызывает `register`/`unregister`, затем перечитывает статус; `OpenSystemSettings` открывает настройки входа.

## 5. Навигация

Маршрутов внутри окна нет. Красная кнопка или «Скрыть окно» ──▶ скрытое окно при работающем опросе; «Открыть окно» ──▶ видимое окно; обычный щелчок по значку переключает эти два состояния; «Выход» ──▶ завершение Kotlin и дочернего AppKit процесса. Реальный повторный вход с автозапуском — оставшаяся проверка M1-04.
