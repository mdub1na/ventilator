## M1 — модель данных и UI для мониторинга (P1)

- [ ] **M1-01, P1:** Описать `FanSnapshot` и `TemperatureReading`: источник, единица, время измерения, доступность, сырое имя ключа и уровень уверенности в подписи. Рассчитать уровень каждого вентилятора по фактическим RPM и индивидуальному `Mn`/`Mx`, затем взять максимум двух уровней для общего значка; для 0 RPM — 0 делений, для недоступного чтения — неизвестное состояние. **Критерий:** нулевой RPM в системном режиме не выглядит ошибкой; отсутствие датчика не подменяется нулём; границы шкалы и агрегирование двух вентиляторов проверены.

Проверить выбранную версию Material 3 и её API на собираемом примере. Документировать экран и функцию по шаблонам `docs/templates/` с реальными путями в код; предусмотреть работающий, остановленный, недоступный и ошибочный состояния.
- [ ] **M1-03, P1:** Добавить **один совмещённый значок приложения** в строке меню macOS: пятисегментная зелёно-красная шкала по максимальному из индивидуальных уровней двух вентиляторов и подтверждённая температура CPU. Нажатие на него открывает контекстное меню с фактическими RPM обоих вентиляторов, открытием/скрытием окна и явным выходом. **Промежуточный результат 2026-09-22:** [Swift/AppKit прототип](prototype/menu-bar/README.md) собрался; пользовательские снимки подтвердили значок, меню и читаемость белых контуров. После добавления вентилятора с потоком вправо и тонкого белого контура на всех делениях пользователь подтвердил, что значок выглядит хорошо на тёмной строке меню.
