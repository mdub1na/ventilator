# Ventilator

Исследование настольного приложения для мониторинга температуры и управления вентиляторами Mac на Kotlin. Приложение ещё не реализовано; есть прототипы [чтения AppleSMC](prototype/smc-read/README.md), [Kotlin/JVM моста](prototype/kotlin-read/README.md) и [составного значка строки меню](prototype/menu-bar/README.md) для текущего MacBook Pro. Все они работают только на чтение.

Начните с [документации](docs/README.md): там находятся проверенные факты, архитектурные решения и план проверки на реальном оборудовании.

Предложения по разработке и pull request описаны в [CONTRIBUTING.md](CONTRIBUTING.md).
