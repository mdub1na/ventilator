# Ventilator

Ventilator — проект настольного приложения для macOS, которое показывает температуру компонентов Mac и фактические обороты вентиляторов. Долгосрочная цель — безопасное управление скоростью вентиляторов с обязательным возвратом управления macOS при выходе и ошибках. Сначала мы проверяем приложение на MacBook Pro с M3 Pro (`Mac15,7`); поддержка Mac mini и других моделей потребует отдельных испытаний.

> **Состояние проекта:** доступно локальное самостоятельное окно мониторинга в `.app` и отдельный прототип значка строки меню. Они читают AppleSMC и не меняют обороты. Интеграция окна и значка, подписанный дистрибутив и управление вентиляторами ещё не реализованы.

## Что уже работает

- Нативная утилита читает число вентиляторов, их текущие RPM и диапазоны, а также температурные ключи AppleSMC. Для `Mac15,7` показатель `TCMz` предварительно подтверждён как максимальная температура кристалла CPU.
- Kotlin-прототип разбирает JSON-снимок утилиты и рассчитывает пятиуровневую шкалу по фактическим RPM каждого вентилятора. Общий значок показывает больший из двух уровней.
- Прототип значка в строке меню macOS показывает шкалу и температуру CPU; по нажатию открывает меню с RPM обоих вентиляторов.
- Compose Desktop окно показывает CPU, два вентилятора с отдельными шкалами и выбранные температуры; диагностика перечисляет сырые ключи с поиском. При локальном запуске упакованного `.app` на этой модели были получены 252 температурных ключа.

Эти результаты проверены на `Mac15,7` с macOS 27.0. Значения и подписи датчиков нельзя автоматически переносить на другие модели.

## Текущий стек

| Часть | Технологии | Состояние |
|---|---|---|
| Чтение датчиков | C11, IOKit, CoreFoundation, AppleSMC | [Рабочий прототип](prototype/smc-read/README.md), только чтение |
| Обработка показаний | Kotlin/JVM 2.4.20, JDK 25, Gradle, kotlinx.serialization JSON | [Рабочий прототип](prototype/kotlin-read/README.md), получает данные от нативной утилиты |
| Строка меню macOS | Swift, AppKit (`NSStatusItem`) | [Рабочий прототип](prototype/menu-bar/README.md) значка и меню |
| Основное окно | Kotlin/JVM, Compose Multiplatform Desktop 1.12.0, Material 3 `1.12.0-alpha03` | [Рабочее самостоятельное окно](prototype/desktop-app/README.md) с `MaterialExpressiveTheme`, локальный неподписанный `.app` |
| Исследование нативного доступа | Kotlin/Native `macosArm64`, IOKit platform bindings | [Проба](prototype/kotlin-native-iokit/README.md) открывает AppleSMC, но не читает ключи |

Для первой версии чтения выбран Kotlin/JVM → C; Kotlin/Native не входит в этот путь. Возможность Kotlin/Native для будущего привилегированного помощника ещё исследуется. Интеграция окна со строкой меню, автозапуск и управление вентиляторами остаются в плане.

## Запуск прототипов на macOS

```bash
make -C prototype/smc-read build
./prototype/smc-read/smc-read --status-json

make -C prototype/menu-bar build
./prototype/menu-bar/status-item ./prototype/smc-read/smc-read
```

Для проверки Kotlin-прототипа нужны JDK 25 и установленный Gradle; команды приведены в [инструкции окна](prototype/desktop-app/README.md) и [инструкции модели](prototype/kotlin-read/README.md). Для чтения датчиков на испытанном Mac `sudo` не требуется.

Проверенные факты, ограничения и архитектурные решения собраны в [документации](docs/README.md); следующий этап указан в [плане](BACKLOG.md). Условия участия — в [CONTRIBUTING.md](CONTRIBUTING.md).
