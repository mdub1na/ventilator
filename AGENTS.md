# Работа в репозитории

Перед задачей прочитайте [исследование архитектуры](docs/research/research-architecture.md), затем [план](BACKLOG.md), затем относящиеся к задаче документы `docs/features/`, `docs/screens/`, `docs/api/` и `docs/services/`, если они появились. Пока в репозитории нет исходников приложения: предложения в исследовании и плане не считаются реализованным поведением.

При подготовке изменений для GitHub следуйте [правилам контрибуции](CONTRIBUTING.md): одна задача на PR, проверки и документация вместе с кодом.

Не выполняйте запись в SMC и не запускайте команды управления вентиляторами в ходе обычной проверки документации. Read-only прототип находится в `prototype/smc-read/`; не добавляйте в него команду записи. Первые опыты записи относятся к отдельному этапу M2 с проверенным восстановлением системного управления. При изменении аппаратного поведения зафиксируйте модель Mac, версию macOS, источник проверки и фактический результат в исследовании.

Документацию проверяйте через `make check`; отчёты — через `make report`.
